# Changelog

## 1.0 - 2026-11-10

- First version with four detection/remediation pairs for Intune Remediations:
  `DEF.SERVICE.STOPPED`, `DEF.SIGNATURE.OUTDATED`, `DEF.RTP.DISABLED`, `DEF.MDE.NOTONBOARDED`.
- `Invoke-DefenderDetection.ps1` runs all detections locally.
- Not yet tested on a real Windows device.
